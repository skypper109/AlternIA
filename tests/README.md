# Tests

Tous les tests du projet AlternIA.

## Types

### Tests unitaires

Tester chaque module séparément.

### Tests d'intégration

Tester la communication entre :

- RAG
- contexte
- profil
- pédagogie
- LLM

### Tests end-to-end

Tester une question depuis le dispositif jusqu'à la réponse finale.

## Exemple

Question :

"Explique-moi la loi d'Ohm."

Vérifier :

- classe correcte
- matière correcte
- documents corrects
- niveau adapté
- réponse pédagogique
