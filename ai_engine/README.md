# AI Engine

C'est le cerveau logiciel d'AlternIA.

Il transforme une question d'élève en réponse pédagogique adaptée.

## Pipeline

Question élève
→ Orchestration
→ Contexte
→ Profil apprenant
→ RAG
→ Moteur pédagogique
→ LLM
→ Validation
→ Réponse

## Modules

- pedagogy
- rag
- context
- learner
- llm
- orchestration
