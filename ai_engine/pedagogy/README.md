# Pedagogy Engine

Le moteur pédagogique contrôle la manière dont AlternIA enseigne.

## Responsabilités

Il doit déterminer :

- niveau de difficulté
- type d'explication
- méthode pédagogique
- progression
- exemples
- exercices
- indices
- correction

## Exemple

Question :

"Explique-moi la photosynthèse."

Le moteur doit déterminer que l'élève a besoin :

1. d'une définition simple
2. d'une explication
3. d'un exemple
4. éventuellement d'un petit exercice

## Important

Le LLM ne doit pas être seul responsable de la stratégie pédagogique.
