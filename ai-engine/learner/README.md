# Learner Profile

Ce module gère le profil d'apprentissage de l'élève.

## Informations possibles

- classe
- matières étudiées
- niveau estimé
- difficultés
- progression
- notions maîtrisées
- notions faibles
- historique des exercices
- taux de réussite

## Exemple

L'élève échoue régulièrement sur :

- fractions
- équations

AlternIA pourra adapter ses prochaines explications.

## Important

Le profil doit être utilisé pour personnaliser l'enseignement,
pas pour enfermer l'élève dans un niveau fixe.
