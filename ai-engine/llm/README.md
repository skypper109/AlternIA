# LLM

Ce dossier contient l'intégration du modèle de langage utilisé par AlternIA.

## Responsabilités

Le LLM reçoit :

- question
- contexte conversationnel
- contexte pédagogique
- documents RAG
- profil apprenant
- règles pédagogiques

Il produit une réponse.

## Attention

Le LLM n'est pas la source principale du programme scolaire.

Les contenus scolaires doivent prioritairement provenir du RAG.
