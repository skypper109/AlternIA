# Device

Ce dossier contient tout ce qui concerne le dispositif physique AlternIA.

Il fait le lien entre :

- l'élève
- l'interface utilisateur
- le matériel
- le moteur IA

## Sous-dossiers

### frontend

Interface utilisée par l'élève.

Elle doit permettre notamment :

- sélectionner 10ème
- sélectionner 11ème
- sélectionner 12ème
- poser une question
- afficher la réponse
- afficher l'historique
- éventuellement afficher la progression

### hardware

Tout ce qui concerne le matériel physique :

- boutons
- microphone
- haut-parleur
- écran
- alimentation
- GPIO
- capteurs éventuels
- communication avec le moteur IA

Ne pas placer la logique pédagogique ici.
