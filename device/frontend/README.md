# Device Frontend

Interface utilisateur du dispositif AlternIA.

## Responsabilités

Le frontend doit :

- afficher les trois classes
- récupérer la sélection de l'élève
- permettre la saisie d'une question
- envoyer la question au moteur IA
- afficher la réponse
- gérer les états de communication

## Classes disponibles

- 10ème
- 11ème
- 12ème

## Important

Le frontend ne doit pas décider du contenu pédagogique.

Il transmet le contexte au backend / moteur IA.
