# Hardware

Contient le code lié au matériel physique du dispositif AlternIA.

Exemples :

- gestion des boutons
- microphone
- haut-parleur
- écran
- GPIO
- LEDs
- alimentation
- communication série
- I2C
- SPI

## Règle

Le hardware doit rester indépendant du moteur pédagogique.

Il fournit uniquement les données et périphériques nécessaires.
